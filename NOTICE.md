# Avisos sobre fontes oficiais

O código e o conteúdo original do POMI Docs são distribuídos sob AGPL-3.0.

As páginas, normas, catálogos, calendários e demais materiais da Universidade
Estadual de Campinas vinculados pelo portal mantêm seus próprios direitos. A
disponibilidade pública de uma URL não é tratada como concessão de licença
aberta.

O POMI Docs prefere paráfrases, atribuição e links para a fonte original. Apenas
fragmentos mínimos necessários para testes documentais podem ser armazenados,
sempre acompanhados de proveniência e sem dados pessoais desnecessários.

Em decisões acadêmicas, administrativas ou institucionais, prevalece a fonte
oficial vigente da Unicamp.
