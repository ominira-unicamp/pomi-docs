# API REST 

## Contexto
Uma api precisa ter uma interface padronizada para facilitar o uso e desenvolvimento de clientes.

## Decisão 

Foi escolhido o uso de uma API REST[1] para a aplicação, por ser um padrão amplamente usado e conhecido, facilitando o desenvolvimento de clientes.

## Consequencia
Escolha por uma API REST traz simplicidade, já que é um padrão bem difundido, porém limitações em operações envolvendo diversos recursos, e dificuldade para operações mais complexas.

[1]: https://restfulapi.net/
