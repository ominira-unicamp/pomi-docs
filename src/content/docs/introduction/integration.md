---
title: Escolhendo HTTP ou SDK
description: Duas formas de consumir os mesmos contratos públicos.
---

Use HTTP quando quiser independência de linguagem, testar uma consulta ou gerar
seu próprio cliente. A [referência da Data API](/reference/data-api/) contém os
paths, parâmetros, respostas e schemas.

Use o SDK quando estiver em TypeScript e quiser tipos, serialização de filtros,
paginação e erros derivados do contrato. Veja [SDK TypeScript](/sdk/getting-started/).

As duas opções consomem o mesmo contrato OpenAPI versionado por esta documentação.
