Os recursos públicos do POMI pertencem a domínios diferentes. Este mapa serve
para localizar um conceito antes de aprofundar sua semântica ou seu contrato.

## Mapa do modelo

```text
Unit
├── Course ──> CatalogCourse ──> Catalog
├── Program ─> CatalogProgram ─> CurriculumSuggestion
└── Department ─> ProfessorDataPortalProfile

Course ─> Class ─> ClassSchedule ─> Room
           ├─────> StudyPeriod
           └─────> Professor

CalendarEvent     DailyMenu ─> Meal     ExchangeNotice
```

Schemas públicos não são tabelas Prisma, e conceitos do POMI nem sempre possuem
o mesmo nome nas fontes oficiais.
