O POMI preserva a lógica dos requisitos divulgados pela DAC e a representa de forma estrutural. A base institucional é descrita nas <SourceRef id="UNICAMP_DAC_DISCIPLINE_RULES" label="regras de disciplinas e pré-requisitos" />.

O Regimento Geral distingue pré-requisitos plenos, parciais e especiais. Os
nomes em maiúsculas usados pela API são normalizações do POMI; eles não
substituem a redação institucional nem uma decisão acadêmica.

<div class="takeaway">
  <strong>Em uma frase:</strong> <code>any</code> representa alternativas e
  cada grupo <code>all</code> reúne condições que precisam ser satisfeitas em
  conjunto.
</div>

## A forma `any` de grupos `all`

```json
{
  "any": [
    { "all": ["A", "B"] },
    { "all": ["C"] }
  ]
}
```

Leia de fora para dentro: basta satisfazer **qualquer** grupo de `any`, mas é preciso satisfazer **todos** os itens do grupo escolhido. O exemplo equivale a `(A AND B) OR C`.

## Como interpretar cada item

<span id="prerequisite-items" class="section-anchor" aria-hidden="true"></span>

<UnionSemantics name="CatalogCoursePrerequisiteItem" title="Tipos de item" headingLevel="h3" />

Um item `COURSE` aponta para outra identidade de disciplina por `courseId`.
Esse ID é resolvido pelo POMI a partir do código institucional normalizado. Se
a disciplina referenciada não foi resolvida, `courseId` pode ser `null`; o
código publicado não deve ser substituído por uma correspondência aproximada.

## Notação original e representação POMI

O scraper interpreta a notação publicada, normaliza códigos e separa condições
de disciplina de requisitos especiais. A estrutura resultante pertence ao
`CatalogCourse` daquele ano. Quando uma integração precisar exibir ou auditar a
formulação oficial, ela deve conservar o vínculo com o catálogo e sua URL de
origem.

## Como consultar

Os pré-requisitos pertencem a `CatalogCourse`. Consulte a disciplina na edição
do catálogo correspondente; não use `Course` como se a regra fosse invariável.

## Limites de interpretação

- `courseId: null` indica que o código publicado não foi relacionado com segurança.
- Requisitos especiais não devem ser convertidos em disciplinas aproximadas.
- A estrutura normalizada não substitui a redação original para auditoria acadêmica.
- Pré-requisitos pertencem à edição do catálogo consultada.
