`Unit` e `Department` dão contexto institucional a cursos, disciplinas e
docentes. Eles não reproduzem toda a estrutura administrativa da Unicamp.

<div class="takeaway"><strong>Em uma frase:</strong> a unidade organiza uma área institucional; o departamento representa uma subdivisão associada a ela.</div>

## O modelo

```text
Unit
├── Course
├── Program
└── Department
    └── ProfessorDataPortalProfile
```

<div class="table-wrap" tabindex="0">

| Linguagem institucional | Representação POMI |
|---|---|
| unidade de ensino e pesquisa | `Unit` |
| departamento associado à unidade | `Department` |
| sigla usada pelas fontes | `Unit.code` |
| identificador interno | `Unit.id` / `Department.id` |

</div>

O código da unidade é normalizado a partir das fontes operacionais. O `id` é
criado pelo POMI e não deve ser tratado como código institucional.

## Limites de interpretação

- `Unit` não representa automaticamente toda unidade administrativa ou de serviço.
- A mesma unidade pode ser observada pelo catálogo, Caderno de Horários e Portal Docentes.
- `Department.unitId` é uma relação resolvida pelo POMI; não é uma chave global publicada por todas as fontes.
- A frequência de sincronização dessas fontes não faz parte do contrato público.
